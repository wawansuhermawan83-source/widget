# Menjalankan build dari HP

Jika proyek sudah diunggah ke repository GitHub:

1. Buka repository dari browser Samsung.
2. Tekan **Actions**.
3. Pilih workflow **Build Glass Clock APK**.
4. Tekan **Run workflow** dan konfirmasi.
5. Tunggu sampai job berstatus hijau.
6. Buka hasil workflow, gulir ke **Artifacts**, lalu unduh `Glass-Clock-debug-APK`.
7. Ekstrak ZIP artifact dan instal `app-debug.apk`.

Jika tab Actions tidak terlihat, buka repository melalui Chrome/Firefox dan aktifkan **Desktop site** dari menu browser.
