GLASS CLOCK - GLASS WEIGHT PATCH

This patch replaces only GlassClockWidgetProvider.kt.
It increases numeral body stroke weight from 3.4% to 5.8% of glyph height, reduces the neon halo, warms the translucent glass gradient, and makes the colon dots fuller. It retains the custom vector paths, 24-hour HH:mm display, transparent widget background, and resize behavior.

Apply from the Termux project root using unzip -o, then inspect with git diff --no-pager before committing.
